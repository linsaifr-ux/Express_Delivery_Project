How to Run
Ensure you have Flask installed:

    pip install flask

Run the application:

    python app.py

Open your browser and navigate to: http://127.0.0.1:5000


How to create staff account:

Stop the server if it's running (Ctrl+C).

Run the script:

    python create_staff.py

Follow the prompts to enter Name, Password, and Role.

It will generate a Staff ID (e.g., S00001).

Restart the server (python app.py) and log in with that Staff ID and your password.
